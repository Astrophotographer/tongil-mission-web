# 통일탐방 미니 — 서비스 기획서

## 1. 목적

통일교육 현장 탐방을 준비하는 교사·강사·대학생이 **탐방 수업 초안**을 빠르게 만들고, 통일 관련 **주장·질문을 짧게 팩트체크**할 수 있도록 돕는 원페이지 웹 서비스입니다.

## 2. 타겟 사용자

| 구분 | 설명 |
|------|------|
| 주 사용자 | 통일교육·현장체험 수업을 기획하는 **교사·강사** |
| 부 사용자 | 탐방 프로그램을 설계하는 **대학생·교육 실습생** |
| 사용 맥락 | 수업 전 탐방지·학습목표·현장미션 아이디어가 필요할 때, 또는 수업·토론 중 나온 통일 관련 주장을 간단히 검증할 때 |

## 3. 페이지 구성 (4개 섹션)

원페이지(`index.html`) + 상단 앵커 메뉴로 이동합니다.

| 섹션 | ID | 기능 |
|------|-----|------|
| **소개** | `#intro` | 서비스 가치 한 줄, 탐방·팩트체크로 이동하는 CTA |
| **탐방 AI 추천** | `#trip` | 날짜·출발지·일정·대상 입력 → AI 탐방 수업안·주변 장소 표시 |
| **팩트체크** | `#factcheck` | 질문/주장 입력(예시 버튼) → AI 판정·근거 요약 |
| **이용 안내 / FAQ** | `#faq` | API 키·실패 안내·주의사항 |

반응형: 모바일에서 햄버거 메뉴, 폼·결과 영역이 깨지지 않도록 구성합니다.

## 4. 기능 A — 탐방 AI 추천

### API

- **엔드포인트:** `POST /api/trip_recommend`
- **구현:** `api/trip_recommend.py`

### 입력 (필수)

| 필드 | 설명 |
|------|------|
| `date` | 탐방일 (`YYYY-MM-DD`) |
| `origin` | 출발지 (텍스트) |
| `schedule` | 일정 (`half` / `full` / `multi` 등) |
| `audience` | 대상 요약 (학년·인원 등) |

### 처리 파이프라인

```text
사용자 입력
  → 1) LLM(Cody): 탐방지·학습목표·현장미션·nearby_area JSON 생성
  → 2) Kakao Local API: nearby_area 기준 맛집·주변지 검색
       (실패 또는 0건 → 빈 목록, 탐방 본문 생성은 계속)
  → 3) LLM(Cody): 장소 검색 결과를 반영한 Markdown 탐방 수업안
  → JSON 응답 → 화면 카드·본문 렌더
```

### 출력 (화면)

- 추천 탐방지, 추천 이유
- 학습목표·현장미션 목록
- 주변 맛집·장소 목록 (Kakao 성공 시)
- Markdown 형식 수업안 본문

### 실패·예외 처리

| 상황 | 사용자 안내 |
|------|-------------|
| 필수값 누락 | 「필수값을 입력하세요」 |
| LLM 4xx/5xx·타임아웃 | 「잠시 후 다시 시도하세요」 |
| **Kakao Local 실패·0건** | 「주변 장소 정보를 불러오지 못했습니다」(또는 동등 경고) — **탐방 본문은 표시** |
| 요청 처리 중 | 「응답을 기다리는 중…」 |

## 5. 기능 B — 팩트체크

### API

- **엔드포인트:** `POST /api/fact_check`
- **구현:** `api/fact_check.py`

### 입력

| 필드 | 설명 |
|------|------|
| `question` | 확인할 주장·질문 (필수) |

클라이언트에서 예시 문장 버튼으로 입력란을 미리 채울 수 있습니다.

### 처리

- 동일 Cody 호환 LLM으로 짧은 **판정·근거 요약** 생성
- koreaboard의 보드·차트·용어사전 전체 파이프라인은 이식하지 않음

### 출력

- 팩트체크 결과 텍스트 영역

### 실패·예외 처리

| 상황 | 사용자 안내 |
|------|-------------|
| 빈 입력 | 「필수값을 입력하세요」 |
| API 오류·타임아웃 | 「잠시 후 다시 시도하세요」 |
| 요청 처리 중 | 「응답을 기다리는 중…」 |

## 6. 테스트 시나리오

| # | 유형 | 기능 | 조작 | 기대 결과 |
|---|------|------|------|-----------|
| 1 | **정상** | 탐방 | 필수 4항목 입력 후 「추천 받기」 | 로딩 문구 후 탐방지·목표·미션·(가능 시) 주변 장소·수업안 표시 |
| 2 | **정상** | 팩트체크 | 질문 입력 또는 예시 클릭 후 제출 | 판정·근거 요약 표시 |
| 3 | **빈 입력** | 탐방 | 일부 필드 비운 채 제출 | 「필수값을 입력하세요」, 결과 영역 비움 |
| 4 | **빈 입력** | 팩트체크 | 빈 질문 제출 | 「필수값을 입력하세요」 |
| 5 | **API 오류** | 탐방/팩트체크 | 서버 오류 또는 키 미설정 환경 | 「잠시 후 다시 시도하세요」 등 오류 안내 |
| 6 | **Kakao 경고** | 탐방 | Kakao 키 없음·API 실패·검색 0건 | 주변 장소 경고 + **탐방 본문은 계속 표시** |

## 7. 기술·보안 요약

- 프론트: 바닐라 HTML/CSS/JS — API 키를 브라우저에 두지 않음
- 백엔드: Vercel Python Serverless (`api/`)
- 환경 변수: `LLM_BASE_URL`, `LLM_MODEL`, `LLM_API_KEY`, `KAKAO_REST_API_KEY`, (선택) `WEBHOOK_URL`

## 8. 보너스 기능

| 항목 | 내용 |
|------|------|
| 기록·연동 | AI 결과·문의 → 브라우저 `localStorage` + `POST /api/save_result` (선택 `WEBHOOK_URL`로 노코드 알림) |
| 다크 모드 | 헤더 토글, 선택값 저장, OS 선호 반영 |
| 마이크로 인터랙션 | 버튼 눌림, 결과 등장, 섹션 스크롤 페이드 (`prefers-reduced-motion` 존중) |
| 방문자 측정 | Vercel Web Analytics 스크립트 + 로컬 방문 횟수 표시 |
