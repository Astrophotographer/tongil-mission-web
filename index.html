    이용 안내

    API가 실패하면 어떻게 하나요?
    필수값이 비어 있으면 「필수값을 입력하세요」를, 서버·AI 오류나 타임아웃이면 「잠시 후 다시 시도하세요」를 안내합니다. 탐방 추천에서 주변 장소(Kakao)만 실패해도 탐방 본문은 표시됩니다.
    API 키는 어디에 두나요?
    Cody LLM과 Kakao Local 키는 Vercel 환경 변수 또는 로컬 .env에만 설정합니다. 저장소·브라우저·스크린샷에는 키를 넣지 마세요. 변수 이름은 .env.example을 참고하세요.
    보너스 기능은 무엇이 있나요?
    다크 모드, 섹션 등장 애니메이션, Vercel Web Analytics·로컬 방문 횟수, AI/문의 결과의 로컬 기록과 선택적 WEBHOOK_URL 알림이 포함됩니다.
    사용 시 주의할 점은?
    AI 답변은 수업 준비 참고용이며, 최종 팩트는 공식 자료와 교육과정에 맞게 교사가 검토해야 합니다. 개인정보·민감 정보는 입력하지 마세요.
